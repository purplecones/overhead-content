# OH-01 Peregrine

The app's original concept airliner, and the model every aircraft wears until a more specific one matches.
It is generated procedurally by `airplane-studio` in the Overhead repository and exported to GLB with Y up and the nose along -Z, 23.05 m long with a 25.3 m span.
